# Prompt: build the Pane icon pack

You're building **Pane Icons**, a line icon pack for **Pane**, a live-tile home screen for
Android (a Lawnchair fork; repo `github.com/xrenold/lawnchair`, branch `metro`). The icons sit
white on solid-colour or see-through square tiles, so they must read as a single quiet set,
never as a jumble of brand colours.

You produce two things from one source:

1. **A standalone icon pack app** in the standard ADW/Nova format, so Pane, Lawnchair, Nova and
   other launchers can apply it.
2. **The same icons built into Pane**, offered as "Pane icons" in Pane's tile icon pack setting.

Work in stages and stop for review after stage 2 (style sheet) and stage 4 (first 40 icons).

---

## 1. Style

The house style is already defined by 53 generic icons in `tools/pane-icons/glyphs.json`
(path data on a 24 grid) and by Pane's app icon. Match them exactly; reuse those 53 paths as
they are.

- **Grid:** 24 × 24 viewBox. Live area 2–22; keep important strokes inside 3–21.
- **Stroke:** one weight, 1.6 units, white `#FFFFFF`, no fill. Never mix weights in one icon.
- **Joins and caps:** round joins; butt caps (as in glyphs.json). Small dots are tiny closed
  circles (r ≈ 0.8), not zero-length lines.
- **Corners:** square or very slightly rounded (radius ≤ 1). No pill shapes unless the subject
  is round.
- **Geometry:** straight lines, 45° diagonals and true circles/arcs. Simplify hard: aim for 3–8
  strokes per icon. No gradients, shadows, textures or 3D.
- **Colour:** white only. No second colour, no opacity tricks (except where glyphs.json already
  uses one).
- **Text in icons:** avoid letters except where a brand mark *is* a letter or word; then draw it
  as strokes in the same weight, not as a font.
- **Optical size:** every icon should feel the same size as `phone` and `calendar` in
  glyphs.json. Check at 24 px and at 48 px.
- **Brand icons:** reduce each brand's mark to this line style (outline only, 1.6 weight, white),
  the way line icon packs such as Arcticons do. Keep the mark recognisable, drop its colours,
  gradients and fills. Draw every brand icon yourself; don't trace or copy another pack's files.

Deliverable for stage 2: a one-page style sheet (SVG or HTML) showing the grid, keylines, stroke
weight, and 12 sample icons (6 from glyphs.json, 6 new brand icons) on a cobalt `#0050EF` tile, a
black tile and a dark photo, at 48 px and 96 px.

## 2. Source format

- One SVG per icon in `tools/pane-icons/svg/<name>.svg`, 24 × 24 viewBox, stroke-based paths
  only (no `<rect>`, `<circle>`, transforms or groups), `stroke-width="1.6"`, `fill="none"`.
- `tools/pane-icons/mapping.json`: for each icon, the generic category it falls back to and the
  app components it applies to.
- A script `tools/pane-icons/build.py` that generates everything below from the SVGs, so icons
  are drawn once and built many times. Vector drawables keep strokes (`strokeWidth`,
  `strokeColor`, `strokeLineJoin`), no PNGs needed.

## 3. Standalone icon pack app

- Gradle module (or separate small repo), applicationId `app.pane.icons`, minSdk 26, name
  "Pane Icons", its own launcher icon (Pane's cluster mark, see `res/drawable/metro_icon_*.xml`).
- Icons as vector drawables in `res/drawable/`, generated by build.py.
- `res/xml/appfilter.xml` (and a copy in `assets/appfilter.xml` for older launchers) mapping
  `ComponentInfo{package/activity}` to drawables. Include `<calendar>` entries with
  `calendar_1` … `calendar_31` dynamic icons for Google Calendar and Samsung Calendar.
- `res/xml/drawable.xml` listing icons by category, so launchers can offer manual picking.
- Fallback for unmatched apps: `iconback`/`iconmask`/`iconupon` left empty and `scale` 1.0, so
  unmatched apps keep their own icon (Pane draws them on its tiles as they are).
- Activity with the standard icon pack intent filters: `org.adw.launcher.THEMES`,
  `com.novalauncher.THEME`, `com.anddoes.launcher.THEME`, `com.gau.go.launcherex.theme`,
  `com.teslacoilsw.launcher.THEME`, `com.fede.launcher.THEME_ICONPACK`.
- A simple screen listing the icons (grid on black), a "request icons" note pointing to GitHub
  issues, and a licence/credits screen.
- CI: add a job to `.github/workflows/metro-apk.yml` that builds the pack APK as an artifact and
  publishes it to a rolling `pane-icons-latest` release.

## 4. Built into Pane

- Pane already applies any installed icon pack through its "Icon pack" setting
  (`lawnchair/src/app/lawnchair/ui/preferences/destinations/MetroPreferences.kt`, pref
  `metroIconPack`, icon loading in `lawnchair/src/app/lawnchair/metro/theme/MetroIcons.kt`).
- Add a built-in entry "Pane icons" (value `"pane"`) that reads the same generated drawables and
  appfilter from inside Pane, so no second install is needed. Default stays "None".
- On top of the appfilter, Pane matches system roles by intent so generic icons work for any
  brand of phone, SMS, camera, browser, mail, calendar, clock, maps, music, gallery, calculator,
  settings and app store: resolve `ACTION_DIAL`, the default SMS app,
  `MediaStore.ACTION_IMAGE_CAPTURE`, `ACTION_VIEW https:`, `mailto:`, `CATEGORY_APP_CALENDAR`,
  `AlarmClock.ACTION_SHOW_ALARMS`, `geo:`, `CATEGORY_APP_MUSIC`, `CATEGORY_APP_GALLERY`,
  `CATEGORY_APP_CALCULATOR`, `Settings.ACTION_SETTINGS`, `market://details`.
- Credits screen: add "Pane Icons" and note that brand marks belong to their owners.

## 5. Component names

Every appfilter line needs the exact launcher activity. Don't guess them:

- Read them from a real device:
  `adb shell cmd package query-activities --brief -a android.intent.action.MAIN -c android.intent.category.LAUNCHER`
- Cross-check against public appfilter files of open-source packs (component names are facts,
  not artwork; don't copy their drawings).
- Where an app has several launcher activities or changed it across versions, list each.
- Package names below are a starting point; verify each one.

## 7. Store and legal

- Brand marks belong to their owners; say so in the pack's description and credits. Don't use
  brand logos in the Play listing graphics (icon, feature graphic); screenshots of the pack in
  use are fine.
- The pack's own name and icon must not suggest it's made by any brand.
- Licence the pack's original artwork as you and the owner agree (CC BY-SA 4.0 is common for
  icon packs); keep it compatible with Pane's GPL-3.0 when bundled.

## 8. Checks before each review

- Render every icon on cobalt `#0050EF`, black, and a mid-grey photo at 24, 48 and 96 px in one
  contact sheet; fix any that look heavier, lighter, bigger or smaller than `phone`.
- Lint: every SVG is 24 × 24, stroke 1.6, no fills, no transforms.
- Install the pack on a device, apply it in Pane and in Lawnchair, and list apps on the device
  that didn't match.
